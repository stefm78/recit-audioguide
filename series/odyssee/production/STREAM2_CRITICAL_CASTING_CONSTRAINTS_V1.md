## Cloud policy

`CLOUD_TTS_FORBIDDEN_FOR_ODYSSEE_CRITICAL_CASTING`

P4 Sirènes and P6 Ulysse émotionnel must not require Azure Speech or any other cloud TTS provider.

Consequences:

- no Azure Speech resource is to be requested for Odyssée critical casting;
- no cloud credential is a valid blocker or dependency for P4/P6;
- previously prepared Azure H1c work is historical experiment evidence only and must not be executed or promoted;
- GitHub-hosted public Actions remains the preferred autonomous execution lane;
- the NUC may be used only when a scientifically admissible local model is blocked **solely** by GitHub-hosted resource limits;
- the NUC must not be made a mandatory production dependency.

## P4 one-shot casting rule

The Sirens appear in one bounded scene. Therefore long-term character identity continuity is **not** an acceptance requirement for P4.

A local model previously rejected for lineage, age control, or cross-scene identity may be reconsidered for P4 when:

1. the rejection is irrelevant to the one-shot Siren function;
2. French remains acceptable;
3. the performance is stable inside S09;
4. H1b-B polyphony is preserved;
5. the result passes the actual P4 human gates:
   - attraction PASS;
   - French PASS;
   - polyphony useful;
   - cliché NONE or LIGHT;
   - dialogue clearly addressed to Ulysse.

This exception is P4-specific. It does **not** weaken P6.

## P6 continuity rule

Ulysse remains the same established character. P6 still requires:

- identity continuity PASS;

- H1b-B Pénélope, pauses, staging and no-music rule preserved.

No global recast of Ulysse is authorized.
