# Plan de blocs de production — L’Odyssée

## Principe

Pour l’auditeur : une seule œuvre continue.

Pour la production : quatre blocs techniques indépendants, assemblables et reprenables après échec.

Le découpage n’est pas un chapitrage artistique obligatoire.

## Bloc A — L’absence et le nom

Séquences 1 à 4.

Couvre :

- Ithaque occupée ;
- Calypso ;
- Nausicaa ;
- palais phéacien ;
- révélation du nom d’Ulysse.

Budget :

- 0 à ~20 min ;
- environ 2 500 à 3 000 mots.

Risques :

- exposition initiale ;
- identité narratrice / Pénélope / Télémaque ;
- Ulysse naufragé crédible ;
- passage narratrice → Ulysse conteur.

Le bloc se termine exactement au point où Ulysse prend la propriété du récit.

## Bloc B — Le prix du voyage

Séquences 5 à 8.

Couvre :

- Cyclope ;
- Éole / retour presque atteint ;
- destruction de la flotte ;
- Circé ;
- Enfers.

Budget :

- ~20 à 46 min ;
- environ 3 300 à 3 800 mots.

Risques :

- Polyphème sans français dégradé ;
- faute d’orgueil d’Ulysse lisible ;
- diminution de l’équipage ;
- merveilleux sans catalogue ;
- Enfers à faible densité.

## Bloc C — Le dernier équipage

Séquences 9 à 11.

Couvre :

- Sirènes ;
- Scylla / Charybde ;
- troupeaux du Soleil ;
- destruction finale de l’équipage ;
- retour au palais phéacien ;
- transport vers Ithaque.

Budget :

- ~46 à 60 min ;
- environ 1 900 à 2 300 mots.

Risques :

- Sirènes intelligibles et séduisantes ;
- choix impossible face à Scylla ;
- perte de tous les compagnons ;
- retour du flashback au présent ;
- forte compression sans effet résumé.

## Bloc D — Revenir chez soi

Séquences 12 à 15.

Couvre :

- déguisement ;
- Eumée ;
- Télémaque ;
- Argos ;
- Pénélope / étranger ;
- cicatrice / Euryclée ;
- arc ;
- prétendants ;
- lit.

Budget :

- ~60 à 85 min ;
- environ 3 500 à 4 000 mots.

Risques :

- Ulysse déguisé toujours identifiable par l’auditeur ;
- lenteur assumée après les monstres ;
- Argos sans musique sentimentale ;
- violence finale courte ;
- Pénélope conserve son doute ;
- lit plus fort émotionnellement que l’arc.

## Budget global

Cible :

- 11 000 à 12 500 mots ;
- centre éditorial : ~85 minutes ;
- tolérance finale : 75–90 minutes selon durées mesurées.

Aucun texte n’est accéléré artificiellement pour tenir un budget arbitraire.

## Reprise sur incident

Chaque bloc devra pouvoir :

1. valider ses sources ;
2. préflight ;
3. résoudre ses assets ;
4. rendre ses voix ;
5. assembler son mix ;
6. produire son QA ;
7. être repris sans rerendre les blocs déjà qualifiés.

L’assemblage final ne doit pas être l’unique endroit où les erreurs apparaissent.

## Ordre de production

Écriture complète A → D.

Puis probes transverses.

Puis production :

A → B → C → D → assemblage intégral.

Il est possible de rendre B avant que D soit mixé, mais pas avant que la prose complète soit suffisamment stable pour vérifier la cohérence du casting et des arcs.
