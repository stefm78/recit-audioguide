# Direction de performance — L’Odyssée

## Principe

L’identité d’un personnage reste stable ; sa performance peut évoluer fortement.

Ne pas créer un nouveau preset simplement parce qu’un personnage a peur, ment ou chuchote.

La variation doit d’abord venir de :

- rythme ;
- projection ;
- proximité ;
- pauses ;
- intensité ;
- longueur de phrase ;
- contexte acoustique.

## Ulysse

### États principaux

#### Naufragé

- peu de projection ;
- fatigue réelle ;
- phrases économes ;
- aucun héroïsme sonore.

#### Étranger chez les Phéaciens

- contrôle ;
- politesse ;
- voix qui observe avant de se livrer.

#### Conteur du flashback

- présence plus stable ;
- intelligence perceptible ;
- variation claire entre ruse, commandement, peur et regret ;
- ne jamais devenir narrateur de bande-annonce.

#### Cyclope — ruse

- précision ;
- rapidité mentale ;
- humour sec possible.

#### Cyclope — orgueil

- projection plus forte ;
- exaltation brève ;
- le contraste doit rendre l’erreur perceptible.

#### Après les pertes

- moins de brillant ;
- davantage d’économie ;
- fatigue et responsabilité.

#### Ithaque déguisé

- retenue ;
- voix volontairement réduite ;
- ne pas modifier l’identité au point d’empêcher l’auditeur de savoir que c’est Ulysse.

#### Lit

- aucune grandeur ;
- blessure puis précision ;
- la réaction au lit doit paraître intime et immédiate.

## Pénélope

- contrôle de soi ;
- autorité domestique ;
- intelligence sans froideur permanente ;
- fatigue perceptible mais jamais victimisation ;
- face à l’étranger : écoute active ;
- après la victoire : doute réel ;
- test du lit : calme, pas triomphe ;
- reconnaissance : émotion longtemps contenue qui peut enfin céder.

## Télémaque

- jeune adulte, pas adolescent caricatural ;
- début : hésitation et colère mal placée ;
- progression : phrases plus nettes ;
- reconnaissance du père : rupture de contrôle possible ;
- combat : ne pas soudain sonner comme un guerrier vieux de vingt ans.

## Athéna

- très peu d’emphase ;
- précision ;
- aucun souffle mystique systématique ;
- débit calme même lorsque le monde autour accélère.

## Calypso

- chaleur et assurance ;
- pas de séduction forcée ;
- sa proposition doit sembler réellement désirable ;
- au départ : émotion retenue, pas vengeance.

## Nausicaa

- jeune adulte ;
- prudence d’abord ;
- curiosité et décision ensuite ;
- aucune couleur enfantine.

## Polyphème

- articulation française prioritaire ;
- débit plus lent ;
- énergie lourde ;
- ne pas forcer artificiellement le grave au-delà de l’intelligibilité.

## Euryloque

- voix d’homme concret ;
- peut contester ;
- fatigue cumulée ;
- doit rester identifiable dans plusieurs épisodes pour matérialiser la diminution de l’équipage.

## Circé

- autorité calme ;
- danger initial sans cri ;
- seconde phase plus humaine ;
- pas de double personnalité vocale.

## Tirésias

- simplicité ;
- rythme bas ;
- aucun filtre qui fasse perdre les mots.

## Anticlée

- chaleur reconnaissable ;
- émotion retenue ;
- la scène est celle d’une impossibilité physique, pas d’un fantôme spectaculaire.

## Sirènes

- intelligibilité absolue ;
- proximité anormalement convaincante ;
- leur force vient de ce qu’elles semblent parler exactement à Ulysse.

## Eumée

- hospitalité directe ;
- simplicité ;
- aucune noblesse rétrospective.

## Antinoos

- confiance ;
- espace occupé ;
- mépris sans caricature de méchant.

## Euryclée

- âge perceptible ;
- chaleur ;
- reconnaissance par la respiration et l’arrêt avant le cri.

## Doublage contrôlé

Un même provider voice peut servir plusieurs rôles secondaires seulement si :

- ces rôles sont éloignés dans le récit ;
- ils n’entretiennent pas de relation directe fréquente ;
- leurs performances ne cherchent pas à simuler deux identités proches par pitch extrême ;
- le rôle doublé n’appartient pas au noyau Ulysse / Pénélope / Télémaque / narratrice.

## Interdit

- pitch extrême pour fabriquer l’âge ;
- vitesse extrême pour fabriquer la jeunesse ;
- voix enfant pour Nausicaa ou Télémaque ;
- traitement acoustique utilisé comme substitut d’identité ;
- changement de provider voice au sein du même personnage sans décision explicite de recasting.
